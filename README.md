# Noxin Labs Media — releases

Downloads for **Noxin Labs Media**, a local narration studio for YouTube built on the ElevenLabs API. It runs on your own Mac; you use your own ElevenLabs key.

**Install:** open the latest release, download the `.dmg` for your Mac (`arm64` for Apple silicon, `x86_64` for Intel), drag the app to Applications, and open it. The first time, right-click → Open, since the app isn't signed with an Apple Developer certificate. It lives in the menu bar and opens its page in your browser; paste your ElevenLabs key in Settings.

**Updates:** the app checks here once a day and installs new versions itself.

This repository holds only the built app, no source.
